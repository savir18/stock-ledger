Limits and next steps

What the project does not do yet, stated plainly.

Known limits

  • 20,000 demo rows: speed gaps grow with the table
  • TRUNCATE and DROP skip triggers, so no app account may run them
  • Sign-in lockout is kept in app memory and resets on restart
  • Demo passkeys must be changed before real use
  • One MySQL server, no replica

Next steps

  • Barcode scanning on a phone
  • Email alerts when stock reaches the reorder level
  • A read replica for analytics
  • Individual accounts with password reset
  • Recovery drills with backups and binary logs
