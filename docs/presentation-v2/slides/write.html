The write path

One sale, end to end

1

Call

The dashboard runs sp_record_movement. Nothing else can write.

2

Check role

fn_role_can confirms this role may post a sale.

3

Lock

The balance row is locked with FOR UPDATE.

4

Insert

One new ledger row. A trigger validates it first.

5

Update totals

An after-insert trigger updates balance and daily summary.

6

Commit

Any failure rolls the whole thing back.

Slide 7 (1 minute). Follow one sale through the six steps. The key point: the dashboard cannot write to a table directly, it can only call the procedure. The procedure checks the role, locks the balance, inserts one row, the triggers update the totals, and everything commits together or rolls back. The live demo shows this working.
