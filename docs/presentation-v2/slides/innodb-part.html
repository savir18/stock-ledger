Slide 13 (1.5 minutes). The ledger table is partitioned by entry date into ten slices: everything before 2026, eight quarters, and one catch-all for the future. When a report asks for one month, MySQL skips the slices that cannot contain it. In our test a September 2026 report read two of the ten. Two more InnoDB features help: the clustered primary key stores rows in key order, and a composite index on product, warehouse and time finds one item's history quickly. Be honest about the cost: InnoDB does not allow foreign keys on partitioned tables, so a trigger validates every reference instead.
