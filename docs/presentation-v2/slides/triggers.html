Immutability

Four triggers lock the ledger

TriggerFiresWhat it does
trg_ledger_no_updateBefore updateRejects every update
trg_ledger_no_deleteBefore deleteRejects every delete
trg_ledger_biBefore insertValidates each new row
trg_ledger_aiAfter insertUpdates balance and summary

TRUNCATE and DROP skip triggers, so no application account is given those rights.

Slide 8 (1 minute). This is where immutable is enforced by MySQL itself, not by the web page. One trigger blocks updates, one blocks deletes, one validates every new row, and one keeps the balance tables in step. Admit the limit honestly: TRUNCATE and DROP do not fire triggers, so the app account simply does not have those privileges.
