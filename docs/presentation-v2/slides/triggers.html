Slide 9 (1.5 minutes). Top row: a normal insert. Before it is stored, trg_ledger_bi checks the product, the warehouse, the movement type and, for a sale, that enough stock exists. After it is stored, trg_ledger_ai updates stock_balance and the daily summary. The two rows below show the immutability: any UPDATE or DELETE on the ledger hits a trigger that raises an error, so the row never changes. Be upfront about one limit: TRUNCATE and DROP do not fire triggers, so no application account is allowed to run them, and recovery relies on backups plus binary logs.
