Slide 8 (1 minute). This is the heart of the database. Each row says what moved, where, what kind of movement it was, by how much, when, and who did it. The quantity is signed: positive adds stock, negative removes it, and zero is not allowed. A cancelling entry fills reverses_ledger_id with the id of the row it undoes. If asked about the odd primary key: MySQL requires the partitioning column to be part of every unique key, so entry_time joins ledger_id.
