Slide 19 (45 seconds). Three smaller points. When a user cancels an entry, a dialog asks for confirmation and says a new row will be added, so nobody thinks the old row is deleted. The Admin page changes passkeys and shows recent sign-ins, including failed ones. And the layout switches to a menu on a phone, because stock is often counted standing in a warehouse.
