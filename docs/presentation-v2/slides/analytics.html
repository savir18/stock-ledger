Slide 14 (1 minute). Because nothing is ever overwritten, the ledger can answer questions about any point in the past. The table shows six questions and how each is answered. The technique to name is the window function: it computes across related rows without collapsing them, which is exactly what a running balance or a cumulative share needs. The last row is a safety question, not a business one: the reconciliation view compares the sum of the ledger with the stored balance, and any difference is flagged.
