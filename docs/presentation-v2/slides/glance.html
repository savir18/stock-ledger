A quick scorecard so the audience knows the size of the work: twelve tables, four triggers, four procedures that write data, seven reporting views, ten quarterly partitions of the ledger, four roles, about twenty thousand generated movements, and forty-two automated checks (twenty-two on the database plus twenty on the web layer).
